Evaluation methodology & scope

Compute Spearman correlation within each CSV row using the aligned prediction vector and Value. Drop non-finite pairs; exclude groups with fewer than four pairs or constant vectors. Ties use average ranks.

Aggregation: pooled ρ = tanh[Σ(n − 3) × atanh(ρ) / Σ(n − 3)]. Correlations are clipped to ±0.999999 before transformation, following the repository script. Median ρ gives equal weight to valid groups. These summaries do not account for dependence between campaigns.

Direction: for non-kinetic models, reverse DDGun, VESPA, SMINA, Boltz-2 and DSDP for kcat, efficiency and fitness; reverse the other non-kinetic models for Km. This follows the published repository script. Positive ρ indicates agreement after this mapping.

Kinetic models: use the first tuple element for kcat and the second for Km, as labelled by the CSV headers. DLKcat is shown for kcat only. Kinetic-model results are omitted for efficiency and fitness because this website does not infer an unverified output mapping. Therefore not every endpoint contains all 20 models.

The original script references intermediate .joblib files absent from this repository snapshot. This website calculates directly from CSVs and adds explicit finite-value filtering; exact equivalence to all paper figures is not claimed.

REPORTED FINDINGS

What the paper reports

Summary of the published abstract
01

Database scores do not tell the whole story

Kinetic-parameter predictors perform strongly on database subsets but lose their advantage on literature-derived mutagenesis data.

02

Zero-shot methods generalize more consistently

Zero-shot predictors show more consistent, though modest, performance. Combining multiple models improves retrospective precision for beneficial mutants.

03

Prospective experiments test practical utility

In a 150-mutant campaign, ESM-1v prioritization performed best; UniKP underperformed random selection. Exact experimental values are not reproduced here.
